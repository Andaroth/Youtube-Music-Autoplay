# Youtube-Music-Autoplay
Tired of YouTube music asking if you are "still there"? No worries here's a little script to close this dialog automatically :P

## Installation
1. You need a plugin installed in your browser to run this script on youtube.com opening. This script uses [Tampermonkey](https://www.tampermonkey.net/).
2. Copy Paste the content of `tampermonkey.js` in a new script in the plugin.
